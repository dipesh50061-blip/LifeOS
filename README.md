# 🚀 LifeOS

> A personal productivity operating system built with Python, Streamlit, and SQLite.

LifeOS is a personal productivity dashboard designed to bring tasks, habits, goals, focus sessions, notes, analytics, and achievements into one unified system.

Instead of using multiple disconnected productivity tools, LifeOS provides a single local application for planning, tracking, and analyzing daily progress.
